# **Java To-Do List Application**

## **Project Description**
This is a simple **To-Do List application** developed in Java, utilizing Java's built-in **LinkedList** framework. It allows users to manage their tasks efficiently through a console-based interface.

---

## **Features**
- **Add Tasks**: Easily add new tasks to your to-do list.
- **View Tasks**: Display all current tasks in the list.
- **Remove Tasks**: Delete tasks once completed or no longer needed.
- **Mark Tasks as Completed**: Keep track of completed tasks.

---

## **How to Run the Project**
### **1. Prerequisites**
- **Java Development Kit (JDK)**: Ensure Java is installed on your system.
- **Command-Line Interface**: Use terminal or command prompt.

### **2. Clone the Repository**
```bash
git clone https://github.com/MahiiBamba/to-do-list.git
cd to-do-list
```

### **3. Compile the Program**
```bash
javac MainFile.java
```

### **4. Run the Program**
```bash
java MainFile
```
